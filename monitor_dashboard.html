◉ Monitor de cambios · múltiples algoritmos

Para repositorios y carpetas locales o páginas web públicas, con MD5, SHA-256, SHA-512 y BLAKE3. Guarda el historial exclusivamente en Engineer/.private/change-monitor.sqlite. Las comprobaciones automáticas funcionan mientras Engineer esté ejecutándose.

Nuevo objetivo

SHA-256 es el valor predeterminado recomendado.

Al configurarlo, Engineer consulta los deployments GitHub cuando detecta cambios web. Solo muestra candidatos respaldados por registros de éxito; no certifica el contenido servido.

Al activarlo se almacenan fragmentos del código o texto web en la base local .private, excluida de Git. No actives esto en carpetas con información sensible. Hasta 60 archivos de texto pequeños por objetivo.

La primera lectura crea una referencia. Si cambiás el algoritmo de un objetivo existente, Engineer restablece esa referencia para evitar comparaciones entre hashes incompatibles. MD5 es solo para interoperabilidad heredada: no ofrece protección fiable contra manipulaciones deliberadas. Las consultas web no siguen redirecciones ni ejecutan JavaScript.

Límites: 1 MB de respuesta web, 8000 archivos por carpeta y 32 MB por archivo (los mayores se revisan solo por metadatos). No descarga ni ejecuta software observado.

💿 Comprobar ISO o archivo descargado

Compará un archivo local con la huella publicada por su proveedor, incluso si pesa varios GB. Se lee por bloques y no se sube.

Si el hash coincide, tenés igualdad respecto de ese valor. Para confirmar autenticidad, obtené el hash de una fuente confiable. MD5 es vulnerable a colisiones deliberadas.
